# IoT Natural Disaster Monitoring System

An IoT-based system for monitoring multiple natural-disaster-related
conditions using sensors and microcontrollers.

## Modules

### 🌍 Earthquake Detection [Version 1.0](eartquake/eartquake.ino)
ESP32 + MPU6050

Detects abnormal ground vibrations using:
- Baseline calibration ✅
- Vibration analysis ✅
- Peak detection ✅
- Oscillation analysis
- Frequency analysis
